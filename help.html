Preguntas Frecuentes

¿Necesito saber programar para empezar?

No, pero ayuda. Empezamos desde cero con comandos básicos de Linux. Si sabes usar la terminal, puedes empezar.

¿Cómo instalo Kali Linux?

Recomendamos usar una máquina virtual (VirtualBox o VMware). En el Plan Free tienes un tutorial paso a paso.

¿Los scripts funcionan en otras distros?

Sí, la mayoría son scripts de Bash o Python que funcionan en cualquier distro basada en Debian/Ubuntu, aunque están optimizados para Kali.
